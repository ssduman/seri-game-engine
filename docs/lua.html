Lua scripting reference

Scripts

Scripts are written in Lua 5.5. The file name is the script name. Lua script returns the script class and the engine calls callbacks functions defined on it. All callbacks are optional and scripts on inactive entities receive nothing.

Attach a script to an entity with the Script Component in the inspector. Reach the entity that the script attached to with self.entity. An entity can have more than one Lua scripts.

Entries in the class's fields table are serialized to inspector then back to the script. Read speed field as self.speed.

local Mover = {
    fields = {
        speed = 2.0,
    },
}

function Mover:OnStart()
    print("moving", self.entity.name, "at", self.speed)
end

function Mover:OnUpdate(dt)
    local transform = self.entity.transform
    transform.position = transform.position + Vec3(0, 0, -1) * (self.speed * dt)
end

return Mover

Examples

A menu button that talks to another script

local MenuButton = {
    fields = {
        action = "play",
    },
}

function MenuButton:OnClick()
    if self.action == "exit" then
        Application.Quit()
        return
    end

    local manager = Scene.Find("GameManager")
    local game = manager and manager:GetScript("GameManager")
    if not game then
        Log.Warning("GameManager script not found")
        return
    end

    if self.action == "play" then
        game:StartGame()
    elseif self.action == "menu" then
        game:ShowMenu()
    end
end

return MenuButton

Creating UI from a prefab

function GameManager:CreateCell(x, y, color)
    local entity = Scene.Instantiate("Cell", self.board)
    entity.rect.size_delta = Vec2(self.cell_size - 2, self.cell_size - 2)
    entity.sprite.color = color
    entity.rect.anchored_position = Vec2(x * self.cell_size, y * self.cell_size)
    return entity
end

Updating text

function GameManager:OnStart()
    self.score = 0
    self.score_text = Scene.Find("ScoreText")
end

function GameManager:AddScore(points)
    self.score = self.score + points
    self.score_text.text.text = string.format("Score %d", self.score)
end
