Lua scripting reference

Scripts

Scripts are written in Lua 5.5. A script is a .lua file in the project's assets folder. The file name is the script name, so assets/project/scripts/Mover.lua defines a script called Mover. The file returns a table, the script class, and the engine calls the functions defined on it. A file can also define a global table with the same name instead of returning one.

Attach a script to an entity with the Script Component in the inspector. Each entity gets its own instance: inside a callback, self is that instance and self.entity is the Entity it is attached to. An entity can run several scripts.

Entries in the class's fields table are shown in the inspector, where each entity can override them, and are copied onto the instance, so the script below reads its speed as self.speed. All callbacks are optional, and scripts on inactive entities receive none.

local Mover = {
    fields = {
        speed = 2.0,
    },
}

function Mover:OnStart()
    print("moving", self.entity.name, "at", self.speed)
end

function Mover:OnUpdate(dt)
    local transform = self.entity.transform
    transform.position = transform.position + Vec3(0, 0, -1) * (self.speed * dt)
end

return Mover

Callbacks

CallbackWhen it runs
OnCreate()The instance was created and self.entity is set.
OnEnable()The script became enabled. On the first frame this comes before OnStart.
OnStart()Once, before the first OnUpdate of the instance.
OnFixedUpdate(dt)Every fixed step, before physics. dt is the fixed step in seconds.
OnUpdate(dt)Every frame. dt is the frame time in seconds.
OnLateUpdate(dt)Every frame, after every script's OnUpdate. Use it for cameras that follow other entities.
OnClick()The entity's Button was clicked. Runs before OnUpdate in the same frame.
OnCollisionEnter(other)The entity's collider started touching another collider. other is the other Entity.
OnCollisionExit(other)The colliders stopped touching.
OnTriggerEnter(other)Like OnCollisionEnter, when either collider is a trigger.
OnTriggerExit(other)Like OnCollisionExit, when either collider is a trigger.
OnDisable()The script was disabled, or is being destroyed while enabled.
OnDestroy()The instance is being destroyed: the entity was removed, play mode stopped or the script was reloaded.

Modules and libraries

require looks in the project's assets/project folder, so require("scripts.util") loads assets/project/scripts/util.lua. Every .lua file in the assets is also registered as a script, so a module shows up in the script list too.

The standard libraries loaded are base, package, math, table, string and utf8. io, os, coroutine and debug are not available.

Examples

A menu button that talks to another script

local MenuButton = {
    fields = {
        action = "play",
    },
}

function MenuButton:OnClick()
    if self.action == "exit" then
        Application.Quit()
        return
    end

    local manager = Scene.Find("GameManager")
    local game = manager and manager:GetScript("GameManager")
    if not game then
        Log.Warning("GameManager script not found")
        return
    end

    if self.action == "play" then
        game:StartGame()
    elseif self.action == "menu" then
        game:ShowMenu()
    end
end

return MenuButton

Creating UI from a prefab

function GameManager:CreateCell(x, y, color)
    local entity = Scene.Instantiate("Cell", self.board)
    entity.rect.size_delta = Vec2(self.cell_size - 2, self.cell_size - 2)
    entity.sprite.color = color
    entity.rect.anchored_position = Vec2(x * self.cell_size, y * self.cell_size)
    return entity
end

Updating text

function GameManager:OnStart()
    self.score = 0
    self.score_text = Scene.Find("ScoreText")
end

function GameManager:AddScore(points)
    self.score = self.score + points
    self.score_text.text.text = string.format("Score %d", self.score)
end
