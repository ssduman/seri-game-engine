Seri Game Engine

A 2D/3D game engine written in C++20 on OpenGL with entity-component system, PBR rendering, shadows, Jolt physics, Lua scripting and fully-featured editor for building and shipping games.

Download for Windows Download for Linux

Features

Entity component system

Scene is entities of EnTT with transform, light, camera, UI, physics and script components that serialized as YAML.

Rendering

Forward renderer with PBR, directional, point and spot lights, shadow mapping, skybox, instancing and post process.

Models and animation

Model loading through assimp, skinned meshes and skeletal animation driven by an animator component.

Physics

Jolt Physics rigidbodies with box, sphere and capsule colliders, collision and trigger callbacks, and raycasts.

Lua scripting

Lua scripts with lifecycle callbacks, fields and hot reload support.

UI and text

Canvas UI with anchored rects, sprites, buttons and FreeType text rendering.

Editor

Dear ImGui editor with docking panels, hierarchy, inspector, project browser, console, gizmos, scene and game view.

Projects and builds

Launcher to create and open projects, prefabs, and export to standalone game.

Tooling

Tracy profiler and premake actions to install, build, package and document the engine.

Scripting

Gameplay is written in Lua. A script is a Lua file that returns a table and is attached to an entity with the Script Component. The example moves its entity with WASD.

  • Entries in fields show up in the inspector and are read as self.speed.
  • Callbacks such as OnStart, OnUpdate and OnCollisionEnter are optional and called by the engine.
  • self.entity gives the entity and its components like transform, rigidbody and collider.
  • Globals such as Input, Scene and Time reach the rest of the engine.

Lua scripting

local Mover = {
    fields = {
        speed = 2.0,
    },
}

function Mover:OnUpdate(dt)
    local dir = Vec3(0, 0, 0)

    if Input.GetKey(Key.w) then dir.z = dir.z - 1 end
    if Input.GetKey(Key.s) then dir.z = dir.z + 1 end
    if Input.GetKey(Key.a) then dir.x = dir.x - 1 end
    if Input.GetKey(Key.d) then dir.x = dir.x + 1 end

    local transform = self.entity.transform
    local step = dir:Normalized() * (self.speed * dt)
    transform.position = transform.position + step
end

return Mover

Get started

Download

  1. Download from latest release.
  2. Extract it and run Editor.exe on Windows or ./Editor on Linux.
  3. Create a project or open a sample project in the projects folder.

Build from source

./seri.sh install                 # or seri.bat on Windows
./seri.sh generate
./seri.sh build --config=release

See INSTALL.md for the full steps.
